# Mario rider sprites

Original 24 × 32 SVG pixel art for Garage Rider, showing Mario from TheBoardGarage riding a Onewheel.
The facial reference is his [interview with Louis Rossmann](https://www.youtube.com/watch?v=S6iMAHeroQA): shaved head, round clear-lens glasses, full dark beard, and a grey shirt with an orange graphic.
The head is exaggerated slightly so the glasses remain readable at the game's smallest display size.

The four assets share one silhouette and origin: riding and jumping, facing either direction.
They use flat colors and simple paths, and the Slint compiler embeds them for the software renderer.
The photographic reference is not included in the firmware.
